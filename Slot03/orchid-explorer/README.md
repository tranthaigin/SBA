# Orchid Explorer Dashboard - Slot 03

## Course
SBA301 - Integrate Single Page Application with Spring Boot
Slot 03 - React Component Architecture & React-Bootstrap

## Component Tree
```text
main.jsx
 └── App
      ├── AppNavbar
      ├── HeroSection
      ├── QuickStats
      ├── OrchidGallery
      ├── CareTips
      ├── LearningAlert
      └── AppFooter
```

## Features
- **AppNavbar**: Responsive brand and navigation links using React-Bootstrap.
- **HeroSection**: Hero banner with gradient background and call-to-action buttons.
- **QuickStats**: 3 Bootstrap summary cards using Container/Row/Col grid.
- **OrchidGallery**: 6 orchid cards rendered with SVG images, tags, and action buttons.
- **CareTips**: 3 responsive care tip cards (Light, Water, Airflow).
- **LearningAlert**: Educational architectural reminder connecting Slot 03 to Props in Slot 04.
- **AppFooter**: Persistent application footer.
